    运行明细

    设置

    所有设置和数据只保存在你这台电脑的浏览器里，不会上传到任何地方。

    1. 连接大模型

    用你自己的 key，费用由服务商直接向你收取。浏览器会直接请求服务商，不经过 Scout 或任何第三方。

    去哪里申请 key ↗
    申请 Tavily key ↗
    高级：转发地址

    有的服务商不允许网页直接调用。可以按 README 部署一个自己的转发程序（Cloudflare Worker，免费），把地址填在这里。

    2. 人群库

    搜索时能选的人群。「识别线索」会交给 AI，写这个人群常用的语言、国旗、标签和搜索词，{city} 会替换成城市名。

    3. 国家和城市

    城市用英文名，多个城市用逗号分隔。

    4. 数据备份

    博主、跟进记录、模板和设置都在这个浏览器里。换电脑或清理浏览器前，先导出备份。备份里不包含 API Key。

    关于

    Scout 是一个开源项目（MIT 许可证）。网页更新后刷新即可用上最新版，你的数据不受影响。

    使用须知：只收集博主公开展示的信息；判断人群只依据博主自述和内容语言，不根据长相推断；请遵守各平台规则和当地隐私法规，不要用于批量骚扰。
